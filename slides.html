0:13 · The scope shape On the Hub → SMART Goals

SHIP it.

S
Size it. Hours a week times weeks, fixed in advance. The scope bends to fit the time, never the reverse.
H
Hone one slice. The thinnest version that works end to end. One feature, one page, one chair, one client. Everything else is version two.
I
Invite one real user. One person actually uses it before you call it done.
P
Publish by a date. A repo with a README, a post, a demo video, a listing. If nobody can find it, it did not happen.
SHIP, in one lineSize: hours a week × weeks. Hone: a user can one action and see one result. Invite: one person tries it. Publish: on repo / post / demo / listing by date.
